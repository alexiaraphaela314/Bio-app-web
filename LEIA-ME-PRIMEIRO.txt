BIOMUNDO - AVENTURA DAS CELULAS
VERSAO 2.0.0 - REVISAO DE 18/11/2026

1. Extraia todo o ZIP.
2. Abra a pasta biomundo.
3. No computador, abra index.html no Chrome/Edge ou use INICIAR-WINDOWS.bat.
4. Mantenha assets, css e js junto de index.html.
5. Opcional: SERVIDOR-LOCAL.bat utiliza Python 3 e http://localhost:8000.
6. Para Android, consulte docs/publicacao.md para hospedagem HTTPS.
